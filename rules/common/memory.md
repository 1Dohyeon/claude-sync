# MEMORY RULE

적용 범위: 메모리(`~/.claude/projects/<프로젝트>/memory/`)에 무언가를 저장하거나 고치려 할 때.

- 기억해 둘 내용이 있으면 메모리에 직접 쓰지 않고, 메모리에 어떻게 쓸지 원문과 함께 제안한다.
  - 사유: 메모리 목록(`MEMORY.md`)은 매 세션 자동으로 주입된다. 확인 없이 쓴 내용은 잘못되었거나 그 대화에서만 맞는 것이어도 이후 세션의 행동을 조용히 바꾸고, 장기적으로 진행하는 업무에서는 그런 항목이 계속 쌓여 메모리 파일이 커진다.
- 어느 프로젝트에서 세션을 열었든 똑같이 적용한다. 메모리는 그 세션을 연 프로젝트의 메모리 폴더를 말한다.
  - 사유: 메모리 폴더가 프로젝트마다 따로 있어서, 이 규칙이 특정 프로젝트에만 적용된다고 오해하기 쉽다.
