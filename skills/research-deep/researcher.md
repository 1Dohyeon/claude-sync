# 조사 서브에이전트 지침

[`research-deep`](./SKILL.md)이 하위 질문 하나를 맡긴 서브에이전트가 읽는다. 다른 하위 질문은 다른 서브에이전트가 맡고 있으므로, 받은 범위만 조사한다.

## 공통 규칙

[`research`](../research/SKILL.md)의 "출처"와 "출처를 신뢰하지 않는다"를 먼저 읽고 따른다.

## 조사 방법

1. 받은 질문에 답하려면 무엇을 모르는지 정한다.
2. 짧은 검색어(5단어 이하)로 검색한다. 같은 검색어를 반복하지 않고 표현을 바꾼다.
3. 쓸 만한 결과는 페이지 본문을 가져와 읽는다. 스니펫만 보고 적지 않는다.
4. 1~3을 반복한다. 검색과 페이지 읽기는 가능한 한 병렬로 부른다.

아래 중 하나에 해당하면 멈춘다.

- 받은 질문에 출처가 붙은 답을 모두 찾았다.
- 새로운 정보가 더 나오지 않는다.
- 도구 호출이 15회에 가까워졌다.

## 출처 판단

- 추측("~할 수 있다", "~로 예상된다")과 확인된 사실을 구분한다.
- 요약·재인용 사이트보다 원 출처를 쓴다.
- 최근 주제는 학습 지식보다 검색 결과를 따른다.
- 출처끼리 다르면 하나를 고르지 말고 양쪽을 적는다.

## 노트 형식

받은 경로에 Write로 저장한다. 최상위 섹션은 아래 구조만 쓴다.

```markdown
# {맡은 하위 질문}

## {세부 질문 1}

### 요점
{1~2문장 결론}

### 출처가 있는 사실
- {사실, 수치, 주장}: [출처](URL)
- {사실}: [출처 A](URL), 반대 내용: [출처 B](URL)

### 추론
- {위 사실에서 끌어낸 판단}

### 못 찾은 것
- {답하지 못한 질문과 그 이유}

<!-- 세부 질문마다 반복 -->
```

- 출처를 대지 못한 사실은 "못 찾은 것"으로 옮긴다. 수치나 사실을 지어내지 않는다.
- 노트만 읽고 보고서를 쓸 수 있도록 구체적인 사실을 적는다. 막연한 요약은 쓰지 않는다.
- 마지막 응답에는 저장 경로와 요점 몇 줄만 낸다.
