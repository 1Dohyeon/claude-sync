# 새 기능 작업 규칙

[`SKILL.md`](./SKILL.md)의 공통 규칙 위에서, 유형이 새 기능일 때 따르는 규칙이다.

## 시작 전

- 코드를 쓰기 전에 요구사항과 성공 기준을 확정한다. 요구사항 원문이 없거나 성공 기준을 판정 가능한 형태로 쓸 수 없으면 사용자에게 묻는다.
- 규모가 standard 이상이면 [`/analyze-task`](../analyze-task/SKILL.md)를 먼저 거치자고 제안한다. 이미 거쳤으면 그 결과를 설계의 근거로 쓴다.

## 테스트

- 새 동작을 표현하는 실패 테스트를 먼저 작성하고 통과시킨다.
