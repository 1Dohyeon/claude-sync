# 리뷰

## 범위 정하기

아래 순서로 범위를 정한다. 앞에서 정해지면 멈춘다.

| 순서 | 조건 | 범위 |
| --- | --- | --- |
| 1 | 인자로 `diff`나 `pr`을 받음 | 그 범위 |
| 2 | PR 번호나 링크가 있음 | `pr` |
| 3 | "push 전", "커밋 전", "지금 작업한 것"처럼 원격에 올리지 않은 변경을 가리킴 | `diff` |
| 4 | 위로 정해지지 않음 | `git status -sb`로 커밋하지 않은 변경이나 push하지 않은 커밋이 있으면 `diff`를 추천하고, 없으면 PR 번호를 묻는다 |

- 사유: 범위를 잘못 고르면 엉뚱한 변경을 리뷰하거나, 리뷰해야 할 변경을 빠뜨린다.

## 이어서

정한 범위의 문서를 Read하고 그대로 따른다. 각 문서가 범위와 축을 확정한 뒤 [`verify.md`](verify.md)로 이어진다.

- `diff`: [`sub/diff.md`](sub/diff.md)
- `pr`: [`sub/pr.md`](sub/pr.md)
